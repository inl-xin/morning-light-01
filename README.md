Entry for the make.fun bounty `u-gudril-cool-two-lines-of-morning-light-ade94fc5`
("Two Lines of Morning Light"), by @inl-xin.

A two-line micro poem about light arriving in the morning: the
kettle clicks off, light slides beneath the door — a letter the
house has held its breath all night to read.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`, byte-identical on repeat runs. Python 3,
standard library only; no network.
